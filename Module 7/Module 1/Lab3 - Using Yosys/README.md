# Lab 3 — First Synthesis with Yosys

## Objective
Explore how a small Verilog design is processed by a synthesis tool.

## Procedure
1. Select the correct RTL source and top module.
2. Read the design into Yosys.
3. Run the synthesis flow appropriate to the exercise.
4. Review the synthesis statistics and generated netlist.
5. Compare the netlist structure with the original RTL.

## Interpretation
Synthesis may simplify logic, combine expressions, or remove unused signals. These changes are expected when they preserve the observable function of the design.
