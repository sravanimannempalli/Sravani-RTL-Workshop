# 1 — Chip Floorplanning

## Objective
Understand the initial physical organization of a chip design.

## Key terms
- **Die:** the overall silicon area.
- **Core:** the region where most standard-cell logic is placed.
- **Utilization:** the fraction of core area occupied by cells, according to the flow's definition.
- **Aspect ratio:** the relationship between core width and height.
- **I/O placement:** assigning locations to external signal pins.
- **Power planning:** creating supply and ground structures.

## Review checklist
Check floorplan dimensions, target utilization, pin placement, macro locations if present, and power-network generation reports.

## Conclusion
A sensible floorplan gives later placement and routing stages enough space to work effectively.
