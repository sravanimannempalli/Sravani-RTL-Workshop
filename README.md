# RTL and Physical Design Workshop — Modules 1 to 9

This repository contains my notes for a workshop covering RTL design, simulation, synthesis, logic optimization, gate-level verification, and introductory physical design using open-source EDA tools.

## Module Index

1. **Module 1:** RTL design foundations and tool setup
2. **Module 2:** Cell libraries, hierarchy, and flip-flops
3. **Module 3:** Logic optimization
4. **Module 4:** Gate-level simulation and RTL/synthesis mismatches
5. **Module 5:** Conditional logic, case statements, and loops
6. **Module 6:** Introduction to SoC design and OpenLane
7. **Module 7:** Floorplanning, power planning, and placement
8. **Module 8:** CMOS inverter, fabrication, and technology files
9. **Module 9:** Cell views, timing tables, and physical design integration

## Tools Mentioned
Icarus Verilog, GTKWave, Yosys, OpenLane, Magic, and ngspice.
