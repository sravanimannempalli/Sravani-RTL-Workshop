# Lab 1 — Development Environment Setup

## Objective
Prepare the basic software environment for RTL coding, simulation, waveform inspection, and source control.

## Checklist
- Install and verify Git.
- Install a text editor suitable for Verilog files.
- Install Icarus Verilog and confirm that the compiler is available from the terminal.
- Install GTKWave and open a sample waveform.
- Install or access Yosys for introductory synthesis exercises.
- Create a working directory and keep source files, testbenches, and generated outputs organized.

## Verification
Record the tool version or command output used to confirm each installation. If a command is not recognized, check the installation path and environment variables.

## Result
The environment is ready when source files can be edited, a simple testbench can be compiled and run, and the resulting waveform can be opened.
