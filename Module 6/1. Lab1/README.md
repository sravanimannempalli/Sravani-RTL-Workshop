# 1 — From Software Intent to Hardware

Computers execute instructions through hardware structures such as processors, memories, buses, and control logic. RTL describes digital hardware behavior and provides a bridge between an architectural idea and a circuit implementation.

## Core concepts
- **ISA:** the instruction-set interface visible to software.
- **Microarchitecture:** the internal organization that implements the ISA.
- **Standard cells:** reusable logic and storage elements.
- **Macros:** larger predefined blocks such as memories or analog IP.
- **Foundry:** the manufacturing facility and process used to fabricate the chip.

A design's physical implementation depends on the chosen technology, libraries, constraints, and verification requirements.
