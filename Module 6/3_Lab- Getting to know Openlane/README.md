# 3 — Exploring OpenLane Project Files

## Objective
Become familiar with the configuration and output structure of an OpenLane design.

## Tasks
- Locate the design's RTL and configuration files.
- Identify the top-level module and target platform.
- Review the clock and I/O constraints.
- Invoke the flow using the documented method for the installed version.
- Locate synthesis outputs, logs, reports, and layout files.
- Check whether each stage completed successfully.

## Troubleshooting
Read the first meaningful error in the log, verify file paths and module names, and confirm that the required PDK and tool environment are available.

## Conclusion
A well-organized project and careful reading of logs are essential for a reproducible RTL-to-layout run.
