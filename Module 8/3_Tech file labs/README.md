# 3 — Technology Files and Layout Rule Checks

## Objective
Become familiar with the technology information required by layout tools and basic cell-design exercises.

## Topics
- Technology-specific layer definitions
- Design-rule constraints
- Cell geometry and spacing
- Layout inspection
- DRC feedback
- SPICE-based characterization inputs

## Workflow
1. Load the appropriate technology setup.
2. Open or create the assigned layout.
3. Check layer assignments and dimensions.
4. Run the available design-rule checks.
5. Review each reported violation and determine its cause.
6. Correct the layout and rerun checks.

## Conclusion
Technology files provide the rules and layer information needed for consistent physical design. Always record the actual tool and technology setup used.
