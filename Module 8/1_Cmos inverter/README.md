# 1 — CMOS Inverter Analysis

## Objective
Explore the operation of a CMOS inverter and relate its electrical response to a SPICE simulation.

## Concepts
- PMOS pull-up and NMOS pull-down networks
- Inverting input/output relationship
- Voltage-transfer characteristic
- Switching threshold
- Propagation delay and output transition time
- Static and dynamic power

## Simulation workflow
1. Define the circuit and transistor models.
2. Create a SPICE deck with supply and input stimulus.
3. Run the simulator.
4. Plot input and output waveforms.
5. Compare switching behavior under the selected conditions.

## Interpretation
The waveform depends on model parameters, transistor sizing, load, and supply voltage.
