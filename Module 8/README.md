# Module 8 — CMOS Inverter, Fabrication, and Technology Files

## Overview
This module examines the CMOS inverter as a fundamental logic cell, introduces the main ideas behind CMOS fabrication, and explores technology-rule and cell-characterization tasks.

## Topics
- NMOS and PMOS operation in an inverter
- Voltage-transfer behavior and switching threshold
- Static and dynamic power concepts
- SPICE deck preparation and waveform inspection
- Overview of CMOS fabrication steps
- Layer identification and design-rule checking
- Technology files and physical design rules

## CMOS Inverter
A CMOS inverter uses complementary PMOS and NMOS devices. The input controls which device conducts, producing an inverted output. Real switching behavior depends on device characteristics, supply voltage, load, and parasitic capacitance.

## Fabrication and Layout
A layout represents shapes on process layers. The manufacturing process transforms these patterns into device structures and interconnects. Design rules constrain geometry and spacing to support manufacturability.

## Key Takeaway
Circuit simulation, physical layout, and technology rules describe different but connected aspects of the same cell.
