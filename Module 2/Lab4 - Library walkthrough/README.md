# Lab 4 — Exploring a Standard-Cell Library

## Objective
Understand the information available in a standard-cell Liberty file.

## Investigation
- Identify the library corner and operating conditions.
- Locate cell names and related functional descriptions.
- Compare variants of a logic cell, such as different drive strengths.
- Observe the timing and power information provided by the library.
- Note that a cell's suitability depends on load, transition, and design constraints.

## PVT Reminder
Process, voltage, and temperature influence device behavior. Timing values from one corner should not be treated as universal values for every operating condition.

## Conclusion
Library inspection helps explain how synthesis selects implementation cells and why cell choice affects area, delay, and power.
